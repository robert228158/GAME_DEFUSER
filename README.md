# GAME_DEFUSER

#### English language: #

To start the game, you need to enter the following command:

**pgzrun main.py**

Required libraries:
> **numpy==2.3.2**
> 
> **pgzero==1.2.1**
> 
> **pygame==2.6.1**

Game genre: **defuser**

**This game is for all ages**

It is based on the game **STANDOFF 2**

Future ideas for the game:
- It’s possible to fix the issue when we start for the first time, if we click on certain points of the initial bomb, 0, 2, 3 get clicked immediately
- You can add new levels and difficulties, as well as a timer
- You can improve the interface
- In the new level, you’ll need to cut not only the internal wires but also the external ones
- Possibly a 3rd level on the BRIZ or PYRAMID map
